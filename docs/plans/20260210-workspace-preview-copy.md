## 需求理解
将旧版会话页面中的文件查看与预览能力完整迁移到新 UI 的工作空间面板，包括多标签页、代码/图片/SVG/HTML/Markdown 预览、二进制提示、滚动同步、行选择与评论。

## 实现方案

### 涉及文件
- `packages/app/src/components/layouts/workspace-panel.tsx`: 扩展为旧版同等的文件树、标签页与预览渲染能力
- `packages/app/src/pages/session-old.tsx`: 作为参考来源，不做修改

### 实现步骤
1. 迁移标签页与文件树交互逻辑，支持打开/关闭/切换/排序与右侧面板布局
2. 复用旧版多格式预览与滚动同步逻辑，涵盖文本、图片、SVG、HTML、Markdown、二进制提示
3. 接入行选择与评论交互，保持与评论上下文的联动与定位

### 风险评估
- 新 UI 布局与样式可能与旧逻辑存在差异，需要适配并避免破坏现有布局
- 预览渲染涉及第三方渲染与 iframe，需确保安全限制与性能可接受
